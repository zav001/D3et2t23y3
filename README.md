# Goobaa Client — DonutSMP 1.21.11 Website

A static, responsive landing page for Goobaa Client, built for DonutSMP on Minecraft 1.21.11.

## Download setup

The site uses a **direct GitHub Release asset URL** for the Download buttons. Visitors are sent straight to the `.jar` download instead of the repository homepage.

Current download:
`https://github.com/zav001/D3et2t23y3/releases/download/v1/GoobaaClient.1.21.11.jar`

### Important privacy note

The website no longer shows a GitHub/source-code button or an "Open Source" section.

A direct GitHub Release URL can still contain the GitHub repository name in the browser's address bar. GitHub does not provide a way to hide that repository name while serving a release asset directly. If you want the download URL to show only your own domain, use a custom download domain/proxy or host the JAR elsewhere.

## GitHub Pages

This project is plain HTML/CSS/JavaScript and can be deployed from the repository root using GitHub Pages.

1. Put `index.html`, `styles.css`, `script.js`, and `.nojekyll` in the root of your Pages repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.

The website itself does not expose the source-code repository through its navigation.
